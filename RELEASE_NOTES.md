# Tuck v0.1.0

First public release of Tuck, a lightweight macOS menu bar todo app for quick personal task capture.

## Highlights

- Menu bar todo capture
- Compact pending and completed todo lists
- Inline editing for title, notes, priority, and due date
- Delete confirmation button
- English / Chinese UI switching
- Local todo storage on your Mac
- Optional natural-language capture when Claude Code CLI is available
- Styled DMG installer with drag-to-Applications layout

## Installation

1. Download `Tuck.dmg` from this release.
2. Open the DMG.
3. Drag **Tuck** into **Applications**.
4. Open Tuck from Applications.

## macOS security note

Tuck is ad-hoc signed for free local distribution, but it is not Apple-notarized.

If macOS blocks it the first time you open it:

1. Open **Applications**.
2. Right-click **Tuck**.
3. Choose **Open**.
4. Confirm that you want to open it.

This only needs to be done the first time.
